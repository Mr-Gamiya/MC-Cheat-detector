## Completion rule

No row is marked “completed” for functional equivalence until its Rust implementation has automated coverage and the test has actually run. Several Rust unit tests already cover bounded archives, renamed JAR hashes, duplicate catalogs, HTML escaping, profile-log parsing and conservative process classification; they remain unexecuted because dependency downloads are blocked at crates.io TCP 443. See `MIGRATION-PLAN.md` for the release blocker and acceptance sequence.
